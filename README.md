# Hariculture

Hariculture est une solution de serre connectée composée de :

- `Api/` : API Node.js, MongoDB et interface avec le Raspberry Pi ;
- `mobile/` : application Flutter Android/iOS.

## Lancer l'API

Consulter [`Api/README.md`](Api/README.md) pour démarrer MongoDB, initialiser la serre
de test et lancer le serveur.

## Lancer l'application mobile

Consulter [`mobile/README.md`](mobile/README.md). En développement, le code
d'association de la serre est `0000`.
